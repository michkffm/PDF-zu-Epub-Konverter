# Branding Assets

Place your project logo and brand files in this folder.

Current logo preview:

![Project Logo](logo.png)

Recommended files:
- `logo.png` (currently used by root README)
- `logo.svg` (optional placeholder/source)

Recommended naming:
- `logo.png` for primary project logo
- `logo-dark.png` for dark backgrounds (optional)
- `favicon.png` for app/web icon usage (optional)

README currently references:
- `assets/branding/logo.png`

Tip:
Use a transparent PNG around 512x512 or wider (e.g. 1200x300) for a clean README header.
